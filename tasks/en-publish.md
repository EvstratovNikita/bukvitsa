# Hootword — английская версия «Буклицы»

Ветка `english`. Игра **Hootword**, совёнок **Pip** (заменяются в `src/i18n/en.js`,
логотип — `LOGO` в `StartMenu.jsx`, заставка — `vite.config.js`).

## Как устроено

- Язык решается до импорта приложения: `main.jsx` → `lib/lang.js`.
- Текст: `tr('Русская фраза')`, перевод в `src/i18n/en.js`. Проверка полноты:
  `npm run i18n:check`. Новая строка без перевода уронит проверку.
- Слова: `data/ru/` (не менять порядок — Слово дня) и `data/en/` — генератор
  `scripts/gen-en-words.mjs`, ручная вычитка `scripts/en-words-review.json`.
  Источник — SCOWL, а не список Wordle.
- Загадываемых слов: 4 буквы 1601, 5 букв 2387, 6 букв 3403 (по уровням).
  Слово дня — из лёгких и средних, день по UTC.
- Правила и экономика общие с русской версией. Ивент «Ночь тыкв» в английской
  версии выключен: загадки не переведены.
- Площадка: `lib/platform.js`; реклама `lib/ads.js`; сохранения `lib/cloud.js`;
  события готовности `lib/lifecycle.js`.

## Что нужно завести на площадках (данные аккаунта — настоящие)

- **GameMonetize:** gamemonetize.com → Dashboard → My games → Add game → GameId
  в `.env.gamemonetize.local`: `VITE_GM_GAME_ID=…`, пересобрать, Verify Game.
- **Telegram:** бот в @BotFather, Mini App, хостинг папки `dist` (https). Кабинет
  Adsgram → блоки за награду и межстраничный. В `.env.telegram.local`:
  `VITE_TG_APP_LINK`, `VITE_ADSGRAM_REWARD_BLOCK`, `VITE_ADSGRAM_INTER_BLOCK`.
- **Playgama:** developer.playgama.com → архив. Файл `playgama-bridge-config.json`
  пустой: содержимое в документации не описано, уточнить при модерации.
- **Яндекс:** в консоли включить английский язык в карточке, добавить название и
  описание на английском. Модерация обычная.
- Адрес поддержки по умолчанию `relagames@yandex.com`; другой — `VITE_SUPPORT_EMAIL`.

## Playgama: разрыв с требованиями (проверено 05.11.2026)

Источник — wiki.playgama.com/playgama/game-requirements и self-check. Номера — пункты правил.

Блокеры модерации:
- [ ] **Звук (3.3, self-check 7).** В игре его нет, а нужны музыка (отдельно меню и партия,
      бесшовный цикл) и эффекты файлами ogg/mp3; синтез в коде отклоняют. Кнопка без звука на
      главном экране и в паузе, состояние сохраняется. Один регулятор: кнопка, платформа
      (isAudioEnabled, AUDIO_STATE_CHANGED), пауза (PAUSE_STATE_CHANGED), реклама, скрытая вкладка.
- [ ] **Эмодзи вместо значков (4.3.2, self-check 15).** 144 вхождения в 21 файле: достижения,
      украшения, угощения, подарки, вкладки, разделы помощи. Нужен свой набор значков.
- [ ] **Только Bridge storage (3.2.1, шаг 4).** localStorage — 28 мест в 14 файлах. Нужно:
      чтение всех ключей при старте одним get, запись пачкой на значимых событиях и перед
      рекламой и скрытием страницы; небольшой набор ключей с полем version.
- [ ] **Межстраничная реклама (шаг 7).** Убрать на Playgama счётчик INTERSTITIAL_EVERY и паузу
      30 с: игра только отмечает паузы, частоту решает Bridge.
- [ ] **Esc (1.5.2).** На Playgama отключить в Modal, Menu, Tour, StartMenu.
- [ ] **Подпись рекламы (2.2.1).** «Double reward» не говорит о рекламе: «Watch ad: ×2 coins».
- [ ] **Пауза (шаг 5).** PAUSE_STATE_CHANGED: остановить таймеры мини-игр и ввод.

Важно проверить или доделать:
- [ ] Слова: убрать из загадываемых религию и политику (4.1.2, 4.1.3).
- [ ] Вёрстка на всех размерах гайда: 360×640, 390×844, 430×932, 844×390, 915×412, 768×1024,
      1024×768, 640×640, 800×450, 1280×720, 1366×768, 1920×1080, 2560×1440, 9:21, 21:9 — все экраны.
      На 844×390 клавиши 30 px, гайд советует ~44.
- [ ] «Поделиться»: только копирование, без системного окна (внешние ссылки, 1.2.6).
- [ ] game_ready — когда заставка убрана, а не когда она ещё на экране (шаг 6).
- [ ] Обложки: 800×800, 1080×1920, 1920×1080; форма: описание, how to play, категория, устройства.
- [ ] Прогон в QA Tool (Test Game), затем отправка на модерацию — её нажимает человек.

Уже соответствует: SDK первым и до загрузки (1.1), архив и конфиг (1.3), обучение и прогрессия
(3.1), английский (3.4.1), нет внешней аналитики и сервера (1.2), длинное нажатие (1.4.5),
реклама за награду только по кнопке и по состоянию rewarded (2.2). Покупок нет — раздел 2.4 не нужен.

Выплаты: минимум $100; банк, крипта по запросу; физлицам — решение в каждом случае отдельно.
Уточнить у Playgama до публикации. Форма: distribution — исключить Playhop/Yandex и VK:
там уже есть своя версия.

MCP: сервер в .mcp.json (игра, сборки, обложки, песочница). Отправить на модерацию, менять
скриншоты и смотреть выплаты через него нельзя.
