# Публикация «Буквицы» в VK Mini Apps

Что уже сделано в коде и что осталось сделать руками в кабинете разработчика.

---

## Что готово в проекте

| | |
|---|---|
| Мост с площадкой | `src/lib/vk.js` — init, хранилище, реклама, данные игрока |
| Прогресс | облако VK, снимок режется на части (лимит ключа) — `bkv_meta`, `bkv_0…N` |
| Экономика | локальная, как на Яндексе: Supabase из сборки вырезан |
| Реклама | `VKWebAppShowNativeAds` за энергию и удвоение монет |
| Сборка | `npm run build:vk` → `dist/` + `buklitsa-vk.zip` |
| Деплой | `npm run deploy:vk` (заливка на хостинг VK) |
| Материалы | `vk-assets/` — иконки и скриншоты |

---

## Шаг 1. Создать приложение

1. Открыть **dev.vk.com** → «Мои приложения» → **Создать приложение**.
2. Тип — **Игра** (не «Мини-приложение»: у игр свой раздел каталога и свои
   правила монетизации).
3. Название — **Буквица**, категория — головоломки/слова.
4. После создания записать **ID приложения** — он понадобится дальше.

## Шаг 2. Прописать ID и залить сборку

1. Вписать ID в `vk-hosting-config.json` вместо `ЗАПОЛНИТЬ_ID_ПРИЛОЖЕНИЯ`.
2. Выполнить:

```bash
npm run deploy:vk
```

Команда соберёт `--mode vk` (Supabase вырезан, тег SDK Яндекса убран),
проверит результат и зальёт `dist/` на **dev-хостинг** VK.

Если удобнее руками: в настройках приложения есть раздел «Хостинг», туда
загружается `buklitsa-vk.zip` — он лежит в корне проекта после сборки.

3. Проверить игру по dev-ссылке из кабинета. Убедиться, что:
   - игра открывается и на десктопе, и в мобильном VK;
   - прогресс переживает перезаход (сыграть партию, закрыть, открыть снова);
   - в меню нет строки входа по почте — её там быть не должно.

4. Когда всё в порядке — в кабинете перевести сборку из dev в **production**.

## Шаг 3. Заполнить карточку

Из папки `vk-assets/`:

- **иконка** — `icon-1024.png`, `icon-512.png`, `icon-256.png`, `icon-200.png`,
  `icon-128.png` (загрузить тот размер, который попросит форма);
- **скриншоты, десктоп** — `desktop-1-board`, `-2-win`, `-3-shop`, `-4-pet` (1280×720);
- **скриншоты, мобильные** — `mobile-1-board`, `-2-win`, `-3-shop`, `-4-pet` (720×1280).

Тексты — в `vk-assets/description.md`.

> Точные размеры изображений форма показывает при загрузке. Если попросит
> что-то, чего в папке нет, — скажите, пересниму: и иконки, и скриншоты
> генерируются из настоящей сборки, размер задаётся одним параметром.

## Шаг 4. Отправить на модерацию

Что смотрят: игра открывается без ошибок, нет битых ссылок и заглушек, контент
соответствует заявленной категории и возрастному рейтингу, скриншоты
показывают саму игру.

Наши слабые места закрыты заранее: шрифты внутри сборки (внешних запросов
нет), Supabase не вызывается, тега чужого SDK нет.

## Шаг 5. Включить монетизацию

Реклама в коде уже подключена, но показы начнутся только после того, как VK
одобрит монетизацию приложения. До этого `VKWebAppShowNativeAds` отвечает
отказом, игра это переживает штатно: награда не начисляется, кнопка просто не
срабатывает.

После одобрения проверить оба места: «посмотреть рекламу» за энергию и
«удвоить награду» после победы.

---

## Что осталось за кадром

- **Таблица лидеров.** В VK-сборке пункт меню скрыт: наша таблица работает
  через Supabase, которого здесь нет. У VK есть свой нативный экран
  (`VKWebAppShowLeaderBoardBox`) — подключается отдельно, если захотим.
- **Время на устройстве.** Суточные кулдауны мини-игр и восстановление энергии
  считаются по часам устройства — как и на Яндексе. Игрок, переводящий время
  вперёд, ускоряет и то и другое. Чинится только переносом счёта времени на
  сторону площадки.
- **Лимит ключа хранилища.** Разбивка рассчитана на снимок до 18 000 символов
  (12 частей). Сейчас снимок ~2 900 символов, запас многократный, но если
  когда-нибудь упрёмся — сборка не молчит: `cloudSave` вернёт ошибку с текстом
  «снимок не помещается».
