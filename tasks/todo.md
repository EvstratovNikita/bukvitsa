# Общая таблица лидеров для VK — план (9 сентября 2026)

## Зачем

Нативный `VKWebAppShowLeaderBoardBox` сравнивает игрока только с друзьями,
у которых игра установлена. Общего рейтинга VK не даёт вовсе — у игр, где он
есть, таблица своя, на своём сервере. В описании карточки уже обещано
«соревнуйся с другими игроками», значит таблица должна быть настоящей.

## Решение

Сервер — уже имеющийся Supabase, тем же способом, что и экономика: таблица
закрыта RLS без политик, наружу торчат две `SECURITY DEFINER` функции.
Клиент площадки ходит в них голым `fetch` (PostgREST), без `@supabase/supabase-js`,
чтобы архив не потяжелел на 245 КБ.

Подпись VK проверяется на сервере (иначе счёт может прислать кто угодно за
кого угодно): параметры `vk_*` по алфавиту, HMAC-SHA256 на защищённом ключе
приложения, base64 → url-safe → без `=`. Алгоритм — из официального примера
VKCOM/vk-apps-launch-params, реализуется на `pgcrypto`.

## Шаги

- [x] `supabase/vk_leaderboard.sql`: таблица `leaderboard(platform, player_id,
      name, score, updated_at)`, PK `(platform, player_id)`, RLS без политик;
      приватная `private.app_secrets` для защищённого ключа
- [x] `submit_vk_score(p_query text, p_score int, p_name text)` — проверка
      подписи, счёт только растёт, потолок прироста и не чаще раза в 30 с
- [x] `leaderboard_top(p_platform, p_player_id)` — топ-20 + место игрока,
      в форме ответа Яндекса (`entries[].player.publicName`, `userRank`)
- [x] Самопроверка в конце файла: фикстура с тестовым ключом печатает ok/fail
- [x] `src/lib/scores.js` — fetch к PostgREST, `VITE_SCORES_URL`/`VITE_SCORES_KEY`
- [x] `src/lib/leaderboard.js` — общий фасад: Яндекс → SDK, VK → наш сервер
- [x] `Leaderboard.jsx` и `useGame.js:283` переводятся на фасад
- [x] `App.jsx` — на VK открывается наша таблица; нативная остаётся кнопкой
      «Среди друзей» внутри модалки
- [x] Имя игрока — `VKWebAppGetUserInfo`, храним имя и первую букву фамилии
- [x] `.env.vk` — адрес и публикуемый ключ; секрет приложения только в Supabase

## Что делает автор сам

Вставляет SQL в SQL Editor и одной строкой кладёт туда защищённый ключ
приложения VK. В переписку ключ не попадает.

## Проверка

1. Самотест SQL прямо в редакторе — подпись считается верно.
2. vk-сборка в песочнице с поддельным хостом VK и локальным PostgREST-моком:
   после победы уходит счёт, модалка рисует топ, гость видит таблицу без строки «я».
3. Отказ сервера не ломает игру: модалка показывает «Таблица недоступна».

## Честно про накрутку

Счёт по-прежнему присылает клиент (как и у Яндекса). Подпись защищает от
«я чужой игрок», но не от «накрутил у себя». Лечится только серверной
проверкой слов — это отдельная работа. Пока: рост монотонный, с потолком.

### Проверено (9 сентября)

- SQL целиком применён на одноразовом кластере PostgreSQL 16 (не на боевом
  проекте): самопроверка подписи печатает три «ok», подделанный `vk_user_id`
  отбивается (`bad_sign`), роль `anon` не может прочитать таблицу напрямую
  («permission denied for table leaderboard»), счёт не убывает, второй рывок
  за 20 секунд отбрасывается, за час прирост срезается до +30, `leaderboard_top`
  возвращает форму лидерборда Яндекса с местом игрока.
- Клиент: vk-сборка поднята с моком PostgREST, в запросах видно сырую строку
  запуска и ключ в заголовках, топ рисуется, при 503 модалка показывает
  «Таблица недоступна», а игра остаётся живой. Тёмная и светлая темы сняты.
- `.env.vk.local` с адресом мока удалён, обе сборки (`vk`, `yandex`) пересобраны.

### Сервер поднят (10 сентября)

SQL применён в боевом проекте, ключ приложения на месте: живой
`submit_vk_score` с посторонней подписью отвечает `{"ok": false, "error":
"bad_sign"}`, а `leaderboard_top` из vk-сборки возвращает пустую таблицу
(«Здесь пока пусто», а не «недоступна»). `.env.vk.local` заполнен из
`.env.local`, сборка пересобрана.

Осталось: вписать ID приложения в `vk-hosting-config.json` и выполнить
`npm run deploy:vk`.

## Причины

1. Правило клавиш для мыши (`@media (hover: hover) and (pointer: fine)`,
   строка ~1688) стоит в файле РАНЬШЕ общего `.key` (~2062) при равном весе —
   оно мёртвое. На компьютере клавиши застревают на телефонном потолке 52 px.
2. Поле растёт до 104 px на клетку, клавиши — нет: пропорция разваливается.
3. На высоких телефонах клавиша упирается в 52, лишняя высота уходит в
   пустую полосу.

      чтобы оно работало; потолок высоты клавиши на компьютере — 64 px,

# Стартовое меню для VK (22.09.2026)

Замечание модерации VK, п. 4.2.10 правил: «Игра должна иметь полноценное стартовое
меню, в котором игроки могли бы ознакомиться со всеми доступными опциями. Также
должна быть возможность вернуться в главное меню игры в любой момент». Делаем
пока только для VK; Яндекс и веб не меняются.

Решения:
- Главный экран `StartMenu` открывается при запуске поверх игры (только `isVk`).
- Возврат в меню — кнопка «Домой» в шапке на месте «гамбургера». Боковое меню в
  VK не нужно: все его пункты переехали на главный экран, двух меню не будет.
- Содержимое: приветствие игрока VK, монеты и энергия; логотип из плиток и
  Букля; «Играть» / «Продолжить»; «Режимы игры»; плитки — Магазин, Букля,
  Достижения, Лучшие игроки, Статистика, Как играть; социальное — Пригласить
  друзей, Поделиться, В избранное (без наград — п. 2.6.2); Настройки, тема,
  Обратная связь. Звука в игре нет — переключатель звука не рисуем.
- Поведение: ежедневная награда может открыться поверх меню; обучение — только
  после выхода из меню; физическая клавиатура не пишет в поле, пока меню открыто;
  Esc — вернуться к игре; «Букля» закрывает меню и открывает питомца.
- Вид: ночное небо (тёмная тема) / утреннее (светлая), стеклянные карточки,
  золотая кнопка с бликом, появление по очереди, `prefers-reduced-motion`;
  влезает в видимую часть фрейма vk.ru (`--app-h`) и в экран 360×640.

- [x] Иконки: дом, друзья, звезда, сетка, сова
- [x] `lib/vk.js`: приглашение друзей, избранное, проверка поддержки метода (`supportsAsync`)

- [x] Обучение: текст шага «Меню» для VK

      320×568, 360×640, 390×760/844, 412×915, 768×1024, vk.ru 1000×604; снимки
      vk-сборки в песочнице (тёмная/светлая, телефон и vk.ru); Яндекс и веб без меню
- [x] Сборки `build:vk` и `build:yandex` (zip), коммит
