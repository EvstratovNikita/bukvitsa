# Премиальный промо-ролик «Буклицы» (1920×1080, 60 fps)

Моушн-дизайн вокруг настоящего геймплея: звёздное небо в цветах обложки,
3D-плитки, логотип из падающих плиток, телефон в перспективе с игрой,
кинетическая типографика, монеты при победе, тёплый перелив фона при смене
темы в магазине, совёнок Букля, финал с кнопкой. Всё в кадре, что относится
к игре, — запись настоящей сборки, ничего не нарисовано поверх интерфейса.

## Как устроено

| Файл | Что делает |
|---|---|
| `capture.js` | Играет в сборку в мобильном вьюпорте 432×768 (DPR 2.5), пишет CDP screencast ~60 fps, пересобирает три клипа (партия, магазин, питомец) в ровные 60 fps, сохраняет метки событий и SVG совы из игры |
| `scene.html`, `scene.js` | Сцена — чистая функция времени `renderAt(t)`; длительности сцен считаются по меткам клипов (монеты — в момент победы, тёплый фон — в момент смены темы) |
| `render.js` | `stills` — 15 контрольных кадров, `full` — все кадры 60 fps |
| `stills.py` | Сетка контрольных кадров с подписью времени |
| `run.sh` | Всё по порядку: серверы, шрифты из сборки, запись, рендер, сборка ffmpeg, выгрузка |

## Запуск (песочница Higgsfield: Playwright + Chromium + ffmpeg)

1. `npm run build:yandex`, `dist/*` положить в `site/` рядом со скриптами, упаковать в zip.
2. `media_upload` на zip и на результаты; PUT zip, `media_confirm`.
3. В песочнице фоном (полный рендер ~4 мин):
   `MODE=both STILLS_URL=… MP4_URL=… SHEET_URL=… bash run.sh`
   (`MODE=stills` — только контрольные кадры для быстрой проверки правок).
4. Смотреть сетку и раскадровку, скачать mp4.

Ссылки для выгрузки — только переменными окружения, в репозиторий не кладём.
Если запись падает — проверить селекторы в `capture.js` (`.key[aria-label]`,
`.shop__subtab`, «Золотая осень», `.pet-headerbtn`, `.owl-svg`).
