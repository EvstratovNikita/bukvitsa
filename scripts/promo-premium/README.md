# Премиальный промо-ролик «Буклицы» (1920×1080, 60 fps, со звуком)

Моушн-дизайн вокруг настоящего геймплея: звёздное небо в цветах обложки,
3D-плитки, логотип из падающих плиток, телефон в перспективе с игрой и наездом
камеры, кинетическая типографика, монеты при победе, тёплый перелив фона при
смене темы в магазине, совёнок Букля, финал с кнопкой. Всё в кадре, что
относится к игре, — запись настоящей сборки, ничего не нарисовано поверх
интерфейса.

Музыка и звук — тоже наши: генеративных музыкальных моделей для отдельного
трека в подключённых сервисах нет, поэтому трек синтезируется кодом по тому же
таймлайну, что и картинка.

## Как устроено

| Файл | Что делает |
|---|---|
| `capture.js` | Играет в сборку в мобильном вьюпорте 432×768 (DPR 2.5), пишет CDP screencast ~60 fps, пересобирает три клипа (партия, магазин, питомец) в ровные 60 fps, сохраняет метки событий, время каждого нажатия и SVG совы из игры |
| `scene.html`, `scene.js` | Сцена — чистая функция времени `renderAt(t)`. Таймлайн лежит на сетке долей (120 BPM, доля 0,5 с): ключевые моменты ставятся на доли, а клип сдвигается так, чтобы победа, смена фона и прыжок попали в долю. Сцена же собирает список звуковых событий `window.SFX` |
| `render.js` | `timeline` — только `timeline.json`, `stills` — 24 контрольных кадра и числовая проверка центровки, `full` — все кадры 60 fps |
| `music.py` | Синтез трека и звуков по `timeline.json` (numpy + scipy): пад, бас, барабаны, щипок, маримба, колокольчики, арфа, подъёмы, удары; свёрточная ревербация, шинная компрессия, предохранитель |
| `audio_check.py` | Проверка звука без прослушивания: волна с метками сцены и сверка ближайших атак с таймлайном |
| `stills.py` | Сетка контрольных кадров с подписью времени |
| `run.sh` | Всё по порядку: серверы, шрифты из сборки, запись, кадры, музыка, громкость по EBU R128, рендер, сведение ffmpeg, выгрузка |

## Звук

- 120 BPM, ре-мажор, ход D–Bm–G–A. Вступление — пад и челеста, логотип — удар и
  маримба по падающим плиткам, грув включается, когда телефон встаёт в кадр.
- Финал нарочно спокойный: тёплый аккорд D — A — D без ударных, плитки финала —
  тихая восходящая пентатоника мягким колокольчиком, подъём перед финалом без
  щелчков и верхов. Звонкие ЧМ-колокола и одинаковые высокие удары маримбы в
  финале резали слух — не возвращать.
- Пад собирается из гармоник до частоты среза (без наложения частот), поэтому
  аккорды не звенят металлом.
- Звуки стоят по меткам записи: нажатия клавиш, перевороты клеток (жёлтая —
  маримба, серая — глухой стук, зелёный ряд «ЗАМОК» — восходящая пентатоника),
  монеты, арфа в момент смены фона, «пружинки» на прыжках совы.
- Громкость: −15 LUFS, ограничитель на 0,9; в mp4 — AAC 192 кбит/с.

## Запуск (песочница Higgsfield: Playwright + Chromium + ffmpeg + python)

1. `npm run build:yandex`, `dist/*` положить в `site/` рядом со скриптами, упаковать (tar/zip).
2. `media_upload` на архив и на результаты; PUT архива, `media_confirm`.
3. В песочнице фоном (полный рендер ~4 мин, музыка ~40 с):
   `MODE=both STILLS_URL=… AUDIO_URL=… MP4_URL=… SHEET_URL=… bash run.sh`
   (`MODE=stills` — кадры и звук без полного рендера, для быстрой проверки правок).
4. Смотреть сетку кадров, волну звука и раскадровку, скачать mp4.

Ссылки для выгрузки — только переменными окружения, в репозиторий не кладём;
presigned-адреса одноразовые и живут несколько часов. Если запись падает —
проверить селекторы в `capture.js` (`.key[aria-label]`, `.shop__subtab`,
«Золотая осень», `.pet-headerbtn`, `.owl-svg`).
