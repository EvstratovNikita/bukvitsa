# Промо-ролик «Буклицы» (горизонтальный, 1280×720)

Настоящий геймплей из сборки `dist`: Playwright играет партию в Chromium,
ffmpeg монтирует 4 сцены — игра панелью справа, подписи на плашке слева,
фон в цветах обложки. Ничего не рисуется поверх игры.

Локально ffmpeg нет — запускаем в песочнице Higgsfield (`sandbox_exec`):

1. `npm run build:yandex`; положить `dist/*` в папку `site/` рядом со
   скриптами этой папки и упаковать всё в zip.
2. `media_upload` на zip и на три результата (mp4, sheet.jpg, frame.jpg);
   PUT zip, `media_confirm`.
3. В песочнице (фоном, работа ~1,5 мин): скачать zip в `/home/user/work`,
   распаковать, `MP4_URL=… SHEET_URL=… FRAME_URL=… bash run.sh`.
4. Проверить `sheet.jpg` (раскадровка) и `frame.jpg` (читаемость подписи),
   скачать mp4.

| Файл | Что делает |
|---|---|
| `record.js` | сценарий записи: КОШКА → ЗАМОК, победа, магазин, фон «Золотая осень», совёнок; пишет `marks.json` |
| `fonts.py` | Manrope из сборки → статический 800 для подписей |
| `make_bg.py` | фон, плашка под текст, маска и тень панели; подбирает размер шрифта под плашку |
| `compose.sh` | границы сцен по `marks.json`, подписи, склейка сдвигом |
| `run.sh` | всё по порядку и выгрузка результата |

Если сценарий падает — первым делом проверить селекторы в `record.js`
(`.key[aria-label]`, `.shop__subtab`, «Золотая осень», `.pet-headerbtn`).
